# Changelog

## [0.4.0] — Визуальный апгрейд

### Добавлено
- Отдельный размытый/затемнённый фон для экрана входа (`aetheros-greeter.png`) —
  читаемость полей логина выше, как в "взрослых" дистрибутивах
- Фирменный акцентный цвет (бирюзовый) во всех GTK-приложениях через
  `gtk.css` — раньше был просто чужой Arc-Dark без своего акцента
- Экран загрузки (Plymouth) переписан: вместо просто пульсирующего лого —
  тонкая полоска прогресса в стиле "луча света" с обоев, растёт по мере
  реальной загрузки системы
- Логотип-связка (маскот + "AetherOS") для диалогов о системе
- **Aether About** — визуальное окно "О системе" (лого, версия, ядро,
  фирменные функции), доступно из меню приложений
- `light-locker` — экран блокировки теперь использует тот же фирменный фон,
  что и экран входа

### Честно
- Это всё проверено только на уровне кода/синтаксиса и логики генерации
  изображений — сам я систему не запускал (нет графики в песочнице сборки).
  Реальный визуальный результат будет виден после сборки ISO на твоей машине.

## [0.3.0] — Для новичков + фирменные фишки

### Добавлено (простота для новичка)
- **Aether Welcome** — мастер первого запуска на простых окнах (zenity),
  кликами объясняет: рабочий стол, как ставить программы, настройки, что
  пароль по умолчанию нужно сменить. Запускается сам один раз при первом
  входе; можно открыть заново значком "Начало работы" на рабочем столе
- На рабочий стол добавлены прямые значки: **Aether Store**, **Aether Info**,
  **Начало работы** — установка программ и помощь доступны в 2 клика,
  без ввода команд
- `aether-info` теперь начинается с 5-строчной шпаргалки на простом языке —
  сложная техническая информация ниже, для тех, кому она нужна

### Добавлено (фирменные фишки)
- **Aether Cycle** — обои сами меняются 4 раза в день (рассвет/день/закат/ночь)
  под текущее время, через systemd-таймер. Ни у одного другого дистрибутива
  нет "живых" обоев из коробки
- **Aether Journal** — личный дневник системы: каждая установка/удаление/
  обновление пакета автоматически записывается с подсказкой отката.
  `aether-journal` показывает историю
- Маленькие фразы-подсказки от призрака-маскота при входе в терминал

### Известные ограничения
- Мастер и звуки в графических диалогах — best-effort (проверить их работу
  можно только после реальной установки, не в песочнице сборки).

## [0.2.0] — Брендинг, звук и удобство

### Добавлено
- Новые обои по умолчанию: тёмный фон с бирюзовым световым лучом (в стиле референса)
- Основной логотип AetherOS — **оригинальный маскот-призрак, нарисованный
  пользователем** (фон убран автоматически, подготовлены все размеры).
  Используется в Plymouth (экран загрузки ПК), в GRUB, как аватар
  пользователя по умолчанию и в виде ASCII-арта (сгенерирован из реального
  изображения) в `aether-info`
- Второй фирменный знак — буква "A" с вытянутой линией, тёмно-зелёный (для
  внутреннего использования / Aether Info)
- 5 системных звуков, синтезированных полностью офлайн (branding/generate_sounds.py):
  запуск, ошибка, системный запрос/предупреждение, фирменный "complete"-звук,
  уведомление — подключены как freedesktop sound theme через dconf
- aether-sound-test — прослушать все 5 звуков
- aether-theme light|dark — переключение темы одной командой
- Полупрозрачность окон и тени (xfwm4 compositor)
- Иконки "Домой"/"Корзина" на рабочем столе
- Автоматический dual-boot: os-prober включён в GRUB
- Автоматическая установка yay (AUR-хелпер) при сборке — полный доступ к Arch/AUR,
  как на обычном Arch Linux, включая пересборку из исходников
- Пасхалки: aether-rain (цифровой дождь), aether-wave (ASCII-волна)
- Данные для входа на live-носителе изменены на admin / admin
- aether-info теперь показывает ASCII-лого и полный список команд —
  фактически встроенная справка "как пользоваться AetherOS"

### Сознательно не сделано (и почему)
- Не встраивали фотографию человека как пасхалку в ASCII-арт — это чужие
  персональные данные, изображение к тому же не было прикреплено к диалогу.
- Не рисовали индивидуальную уникальную иконку вручную для каждого
  приложения в системе — это сотни файлов; вместо этого подключена полная
  профессиональная тема иконок Papirus, а свои иконки сделаны для
  фирменных приложений AetherOS (Aether Store, Aether Info, Aether Settings).



## [0.1.0] — Первый релиз профиля AetherOS

### Добавлено
- archiso-профиль на базе Arch Linux (`profile/`)
- Aether Desktop: кастомизация XFCE (панель, обои, автозапуск)
- Aether Terminal: свой цветовой профиль и приглашение `user@aetheros:~$`
- Команды: `aether`, `aether-info`, `aether-version`, `aether-about`,
  `aether-update`, `aether-repair`, `aether-clean`, `aether-check`,
  `aether-report`, `aether-store`, `network-info`, `wifi-info`, `ip-info`
- Aether Installer на базе Calamares (сценарий установки, разделы, GRUB)
- Фирменный стиль: программно сгенерированные обои и логотип, тема GRUB,
  тема загрузочной заставки Plymouth
- Автоматическая сборка ISO: `build.sh` (Arch Linux) и `docker-build.sh`
  (любая ОС через Docker)
- Дымовой тест загрузки образа в headless QEMU (`tests/smoke-test.sh`)
- Полная документация по сборке (`docs/GUIDE.md`)

### Известные ограничения
- Сборка ISO требует интернет и Arch Linux (напрямую или через Docker) —
  невозможно собрать в полностью изолированной среде без сети.
- Aether Store — простой TUI-каталог поверх `pacman`/`yay`, не GUI-магазин.
