# Как собрать AetherOS

Это руководство рассчитано на новичка: пошагово, без предположений о том,
что вы уже что-то умеете.

## 1. Что нужно установить

**Вариант А — у вас уже есть Arch Linux** (или Arch в виртуальной машине):
```bash
sudo pacman -Sy --needed archiso git base-devel
```

**Вариант Б — у вас Windows, macOS или Ubuntu/другой Linux** (рекомендуется,
если вы не хотите разбираться с Arch Linux):
1. Установите Docker Desktop: https://www.docker.com/products/docker-desktop/
2. Убедитесь, что Docker запущен (иконка кита в трее / `docker --version` в терминале).

Больше ничего устанавливать не нужно — весь остальной инструментарий
(archiso и т.д.) будет автоматически установлен внутри Docker-контейнера.

## 2. Куда положить файлы

Скопируйте (или распакуйте) папку `AetherOS/` целиком куда угодно, например:
```
~/AetherOS/
```
Важно не менять структуру папок внутри — `build.sh` ожидает, что рядом с ним
лежит папка `profile/`.

## 3. Какие команды запускать

**Вариант А (Arch Linux):**
```bash
cd ~/AetherOS
sudo ./build.sh
```

**Вариант Б (Docker, любая ОС):**
```bash
cd ~/AetherOS
./docker-build.sh
```

Сборка идёт 15–40 минут в зависимости от скорости интернета и диска — скрипт
сам:
1. проверяет и ставит зависимости (`archiso`);
2. проверяет синтаксис всех скриптов профиля;
3. скачивает пакеты Arch Linux и собирает файловую систему;
4. добавляет оформление AetherOS (обои, тема терминала, GRUB, Plymouth);
5. упаковывает всё в единый образ;
6. создаёт готовый `AetherOS.iso`.

Всё происходит автоматически — вмешиваться не нужно.

## 4. Как получить ISO

После успешного завершения в корне проекта появится файл:
```
AetherOS.iso
```
Это готовый загрузочный образ.

## 5. Как проверить систему (без реального ПК)

### QEMU
```bash
qemu-system-x86_64 -enable-kvm -m 4096 -cdrom AetherOS.iso
```
(на Windows/macOS без KVM уберите `-enable-kvm`, будет чуть медленнее)

### Автоматический тест
```bash
./tests/smoke-test.sh AetherOS.iso
```
Скрипт сам загрузит ISO в фоне и скажет `PASS`/`FAIL`.

### VirtualBox
1. Создайте новую виртуальную машину, тип "Linux", версия "Arch Linux (64-bit)".
2. Не менее 2 ГБ RAM, 20 ГБ диска.
3. В настройках VM → Storage → добавьте `AetherOS.iso` как оптический диск.
4. Запустите VM.

## 6. Как установить на реальный компьютер

1. Запишите `AetherOS.iso` на USB-флешку. Проще всего через:
   - **Rufus** (Windows) — https://rufus.ie
   - **balenaEtcher** (Windows/macOS/Linux) — https://etcher.balena.io
   - или `dd if=AetherOS.iso of=/dev/sdX bs=4M status=progress` (Linux; `/dev/sdX`
     — это ваша флешка, **не** диск с данными — проверьте через `lsblk`!).
2. Загрузитесь с флешки (обычно клавиша Boot Menu при включении: F12/F11/Esc/Del
   — зависит от производителя).
3. На рабочем столе живой системы дважды кликните "Install AetherOS" —
   откроется Aether Installer (на базе Calamares).
4. Пройдите шаги: язык → раскладка → диск → пользователь → сводка → установка.
5. После установки перезагрузитесь и извлеките флешку.

## 7. Как исправлять ошибки

- **`sudo ./build.sh` ругается, что вы не на Arch Linux** — используйте
  `./docker-build.sh` вместо `build.sh`.
- **`mkarchiso` падает на скачивании пакета** — обычно временная проблема
  зеркала Arch; запустите сборку ещё раз, либо обновите зеркала:
  `sudo pacman -S reflector && sudo reflector --latest 20 --sort rate --save /etc/pacman.d/mirrorlist`.
- **Docker: "permission denied" при обращении к `/var/run/docker.sock`** —
  добавьте пользователя в группу docker (`sudo usermod -aG docker $USER`) и
  перезайдите в систему, либо запускайте `docker-build.sh` через `sudo`.
- **ISO не грузится в VirtualBox** — убедитесь, что в настройках VM включён
  EFI (Settings → System → Enable EFI) или, наоборот, отключён, если вы
  тестируете Legacy BIOS-режим — AetherOS поддерживает оба.
- **Просмотреть лог сборки** — `mkarchiso` пишет подробный вывод прямо в
  терминал; при ошибке ищите первую строку с `ERROR` выше по логу.

## 8. Как добавлять новые функции

- **Добавить программу по умолчанию** — впишите её имя пакета Arch в
  `profile/packages.x86_64` (по одному пакету на строку) и пересоберите ISO.
- **Изменить обои/логотип** — отредактируйте `branding/generate_assets.py` и
  запустите `python3 branding/generate_assets.py` заново — файлы обновятся
  прямо внутри `profile/airootfs/...`.
- **Добавить свою команду** — положите исполняемый bash-скрипт в
  `profile/airootfs/usr/local/bin/` и добавьте его в `file_permissions` внутри
  `profile/profiledef.sh` (чтобы он остался исполняемым в готовой системе).
- **Изменить рабочий стол/панель** — правьте XML-файлы в
  `profile/airootfs/etc/skel/.config/xfce4/xfconf/xfce-perchannel-xml/`.
- **Изменить шаги установщика** — правьте конфиги в
  `profile/airootfs/etc/calamares/modules/`.

Это и есть режим **Aether Forge**: вы полностью контролируете, что попадёт в
следующую версию AetherOS, просто редактируя файлы профиля и запуская
`build.sh` заново.
